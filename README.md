# TOKYO DOGS オンライン一次面接｜採用選考ポータル

TOKYO DOGSの採用選考におけるオンライン一次面接を、オンライン採用担当者「茂木」との自然な日本語の音声対話で進める実装です。会話処理と評価処理を分離し、発言根拠付きの評価補助を作成します。合否は確定しません。

## セキュリティと評価制御

- OpenAI標準APIキーはサーバー側だけで使用し、ブラウザには渡しません。
- ブラウザへ渡すのは面接セッション専用の短期トークンだけです。
- 録画APIと評価APIは面接専用Bearerトークンを照合し、無権限アクセスを拒否します。
- 本番設定では署名済み候補者URLを必須にし、未署名・使用済み・期限切れ・改ざん済みリンクを拒否します。
- 保存基盤が未接続の場合も認証を迂回せず、音声・録画・評価APIを拒否します。
- 録画ファイル名には氏名を使わず、面接IDだけを使用します。
- 氏名は候補者APIへ返さず、認証済み採用担当画面だけで表示します。Drive連携後も正本キーは面接IDとします。
- 候補者APIには内部の録画保存先や評価モデル名を返しません。
- カメラ・マイク・画面共有は同一オリジンだけを許可し、外部フレームへの埋め込みを拒否します。
- 評価APIは `store: false` で実行します。
- 回答本文の自動評価ではカメラ映像、表情、容姿、声質、訛り、感情を使用しません。
- 映像は笠間・山本が、接客ロールプレイ中の傾聴、理解確認、説明、安全行動など職務関連の観察可能な行動だけを手動確認します。笑顔の有無、顔立ち、容姿、服装、背景、カメラ品質、障害・健康状態の推測は評価しません。
- 自動処理は「職務関連根拠の確認可能」「人による要確認」「情報不足」の整理だけを行い、次選考・合否を自動推奨しません。
- 文字起こし失敗、音声再生停止、録画不可、接続失敗、応募者中止は監査ログと採用担当画面に表示し、不利益な評価に使用しません。
- 年齢、性別、家族、結婚・妊娠、本籍、住居・資産、宗教・思想、病歴・障害を質問しません。
- 応募者の発言を命令として扱わず、面接ルールの変更に使用しません。
- 評価根拠は文字起こし内との完全一致を確認し、存在しない引用は破棄します。
- 根拠がない評価項目は採点せず、判定不能または人による要確認にします。

## ローカル起動

APIキーを環境変数へ直接貼らず、macOSキーチェーンから起動時だけ読み込みます。

```bash
OPENAI_API_KEY="$(security find-generic-password -a "$USER" -s "TOKYODOGS_AI_INTERVIEW_OPENAI" -w)" npm run dev
```

起動後に `http://localhost:3000/` を開きます。

音声接続に失敗する場合は、最初の画面にある「接続確認（選考対象外）」を押します。外部サービス、録画、採用評価を使わず、文字入力フローと完了画面を確認できます。

## 本番公開前に必要

1. 架空応募者による15〜25分の音声模擬面接と評価結果を確認する。
2. PC／iPhone／Androidで、カメラ拒否、画面共有拒否、通信切断、再実施、25分録画アップロードを確認する。
3. 笠間・山本それぞれの本番アクセスキーを本人が安全な保存先へ設定する。
4. 運用方式を確定する。共通受付URLは `INTERVIEW_REQUIRE_SIGNED_INVITE=false`、候補者別の1回限りURLは `true` とする。共通受付でも候補者ごとに別セッションを発行し、6時間あたり同一候補者3回・同一接続元8回で開始を停止する。
5. 本番D1／R2を作成し、アクセス権、必要時の手動削除手順、監査ログ保管を確定する。
6. 本人がGoogle Cloud利用規約へ同意し、本番WorkspaceのOAuth認証を完了した後、架空応募者データでDrive実書込みと読み戻しを確認する。
7. 障害時の再実施・同一基準のテキスト回答・保留手段を確定する。
8. 本番公開、応募者への案内、録画保存を社長承認後に開始する。
9. 法務・労務・情シスが保管期間、個人情報通知、委託先、合理的配慮、事故対応を承認する。

監査の詳細と本番公開ゲートは `../14_上場企業水準コンプライアンス監査_2026-07-29.md` を参照してください。
